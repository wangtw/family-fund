## 1. 核心逻辑：30秒看懂“披萨理论”

在乱点按钮之前，先理解系统的“大脑”是怎么思考的，防止你觉得系统算错了。

- **总资产 (AUM)** = 你的现金余额 + 所有股票当前的市值。
- **份额 (Shares)** = 这是一个“绝对数量”，代表你拥有的权益份数。就像你拥有 **5块** 披萨。
- **净值 (NAV)** = **1块** 披萨现在值多少钱。
  - *系统公式*：`净值 = 总资产 / 总份额`
- **赚钱逻辑**：你的**份额数量**通常是不变的（除非你加钱买份额或提钱卖份额）。但随着股票涨跌，**净值**会变大变小，你的总资产（`份额` x` 净值`）也就随之波动。

## 2. 每周五的标准作业流程 (The Friday Ritual)

请像飞机起飞检查一样，按顺序执行这 3 步。

### ✅ Step 1：启动与健康检查

1. **打开文件**：双击 `合伙基金管理系统 v3.8.2.html`。
2. **看右上角胶囊状态**：
   - 🟢 **绿色 (系统正常)**：汇率和股价都更新了，可以开始干活。
   - 🔴 **红色/黄色**：断网或接口卡了。
     - *动作*：点击右上角的 <button>🔄</button> 刷新按钮。或者点击胶囊查看是腾讯挂了还是新浪挂了（v3.8.2 会自动尝试切换备用线路）。
3. **看左上角总资产**：确认数字不是 0。

### ✍️ Step 2：录入本周发生的变动

根据实际情况，选择以下对应的场景操作：

#### 场景 A：买卖股票 (Trade)

> 点击按钮：<button style="background:#e0f2fe; color:#0369a1; border:1px solid #bae6fd; border-radius:4px; padding:2px 6px;">🔵 交易</button>

1. **检查现金**：确保左侧面板的 `现金` 余额够买。
2. **代码**：输入代码（如 `00700` 或 `600519`）。**停手 1 秒！** 等下面显示出股票名称再继续。（系统有防抖保护，防止输错）。
   - *注*：不用管是沪市还是深市，v3.8.2 会自动识别修正（例如自动把 000858 的后缀修正为 .SZ）。
3. **方向/价格/数量**：如实填写。
4. **汇率**：**别动它**，系统会自动填好。
5. **提交**。

#### 场景 B：合伙人入金/加仓 (Money In)

> 点击按钮：<button style="background:#3b82f6; color:white; border-radius:4px; padding:2px 6px;">🟦 资金</button>

1. **合伙人**：下拉选择老名字，或者直接输入新名字（老王）。
2. **类型**：选择 **“入金”**。
3. **金额**：输入人民币金额。
4. **日期**：默认为今天。
   - *⚠️ 警告*：如果是补录以前的入金，**必须**修改日期，并填入那一天的历史净值。否则会发生“时空扭曲”，导致份额计算错误。
5. **确认**。
   - *🤖 旁白*：系统正在用`金额 / 当前净值`计算老王拿到了多少份额。

#### 场景 C：合伙人赎回/提现 (Money Out)

> 点击按钮：<button style="background:#3b82f6; color:white; border-radius:4px; padding:2px 6px;">🟦 资金</button>

1. **合伙人**：选择要提钱的人（如小张）。
2. **类型**：选择 **“出金”**。
3. **金额**：输入他要提走的钱。
   - *如果是彻底清盘退出*：先去主界面看一眼他的“权益市值”是多少，精确填写那个数字。
4. **确认**。
   - *🤖 旁白*：系统会销毁小张名下对应的份额。如果他清盘了，去【设置】-【合伙人管理】把他“隐藏”起来，不要删除，以保留历史数据。

#### 场景 D：收股息或付杂费 (Journal)

> 点击按钮：<button style="background:#fffbeb; color:#b45309; border:1px solid #fcd34d; border-radius:4px; padding:2px 6px;">🟨 收支</button>

1. **科目**：
   - 收钱选 **“股息分红 (+)”**。
   - 扣费选 **“运营支出 (-)”**。
2. **金额/说明**：如实填写。
3. **红利复投**：如果这笔分红马上买了股票，勾选下方的“同时生成红利再投”，系统会接着弹窗让你填买入记录。

### 💾 Step 3：备份 (Backup) —— **最重要的一步**

**不做这一步，前面的功夫可能白费。**

1. 点击右上角的 <button>⚙️ 设置</button>。
2. 点击 **“下载备份 (.json)”**。
3. 浏览器会下载一个类似 `Backup_2026-01-28.json` 的文件。
4. **动作**：将此文件发送给自己的 **微信文件传输助手**、**邮箱** 或 **网盘**。

## 3. 常见问题急救包 (FAQ)

#### Q1: 打开页面一片白，或者数据全是 0，甚至变成了演示数据？

- **别慌**。这是因为浏览器缓存被清空了。
- **解法**：点击 <button>⚙️ 设置</button> -> **“恢复备份”** -> 选择你上周五保存的那个 `.json` 文件。**Boom!** 资产全回来了。

#### Q2: 现金余额跟银行卡对不上怎么办？

- **原因**：可能是利息漏记了，或者汇率波动导致的误差。
- **解法**：点击 <button>⚙️ 设置</button> -> **“现金校准”**。填入你银行卡里现在的**真实余额**。系统会自动生成一笔“平账”记录，强制把账做平。

#### Q3: 录错了一笔交易怎么办？

- **解法 A（立刻发现）**：点击左上角的 <button>↩️ 撤销</button>。
- **解法 B（后来发现）**：看页面最下方的“流水记录”表格，**点击录错的那一行**，会弹出修改窗口（仅限交易记录）。

#### Q4: 我想清空所有数据重新开始？

- **解法**：点击 <button>⚙️ 设置</button> -> **“清空数据”**。
- **密码**：默认密码是 `123456789`。
