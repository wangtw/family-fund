    30秒看懂"披萨理论"

    在乱点按钮之前，先理解系统的"大脑"是怎么思考的，防止你觉得系统算错了。

    • 总资产 (AUM) = 你的现金余额 + 所有股票当前的市值。
    • 份额 (Shares) = 这是一个"绝对数量"，代表你拥有的权益份数。就像你拥有 5块 披萨。
    • 净值 (NAV) = 1块 披萨现在值多少钱。
      • 系统公式：净值 = 总资产 / 总份额
    • 赚钱逻辑：你的份额数量通常是不变的（除非你加钱买份额或提钱卖份额）。但随着股票涨跌，净值会变大变小，你的总资产（份额 x 净值）也就随之波动。
    📅 每周五的标准作业流程
    请像飞机起飞检查一样，按顺序执行这 3 步。
    Step 1：启动与健康检查
    1. 打开文件：双击 合伙基金管理系统 v3.10.1.html。
    2. 看右上角胶囊状态：
      • 🟢 绿色 (系统正常)：汇率和股价都更新了，可以开始干活。
      • 🔴 红色/黄色：断网或接口卡了。
        • 动作：点击右上角的刷新按钮。或者点击胶囊查看是哪个数据源挂了。
    3. 看左上角总资产：确认数字不是 0。
    Step 2：录入本周发生的变动

    根据实际情况，选择以下对应的场景操作：

    场景 A：新增合伙人
    1. 合伙人：在输入框里直接打字输入新名字（系统会自动记录）。
    2. 类型：选择"入金"。
    3. 金额：输入人民币金额。
    4. 日期：默认为今天。
      • ⚠️ 警告：如果这是基金成立的第一笔钱，当时净值 默认为 1.0000。如果不是，系统会自动抓取当前净值。
    5. 确认。
    场景 B：资金注入
    1. 合伙人：下拉选择老合伙人的名字。
    2. 类型：选择"入金"。
    3. 金额：输入人民币金额。
    4. 日期：默认为今天。
      • ⚠️ 警告：如果是补录以前的入金，必须修改日期，并填入那一天的历史净值。否则会发生"时空扭曲"，导致份额计算错误。
    场景 C：资金赎回
    1. 合伙人：选择要提钱的人。
    2. 类型：选择"出金"。
    3. 金额：输入他要提走的钱。
    4. ⚠️ 系统限制：出金金额不得超过权益市值。
    场景 D：买卖股票
    1. 检查现金：确保左侧面板的 现金 余额够买。
    2. 代码：输入代码（如 00700、600519、AAPL）。停手 1 秒！ 等下面显示出股票名称再继续。
    3. 方向/价格/数量：如实填写。
    4. 汇率：别动它，系统会自动填好。
    5. 提交。
    Step 3：备份 (Backup) —— 最重要的一步

    不做这一步，前面的功夫可能白费。

    1. 点击右上角的 ⚙️ 设置。
    2. 点击 "下载备份 (.json)"。
    3. 浏览器会下载一个类似 Backup_2026-01-28.json 的文件。
    4. 动作：将此文件发送给自己的 微信文件传输助手、邮箱 或 网盘。别只放在桌面上！
